Uniang Plastic Industries - website (Sea Green & Steel design)

Open index.html to view the home page. Everything is relative, so the folder can be
uploaded as-is to any web host (cPanel public_html, Azure Static Web Apps, etc.).

  *.html      31 pages (home, about, vision & mission, products + 23 product pages,
              sustainability, events, careers, contact)
  assets/     only the images, logo and mascot video these pages use

Note: the mascot video's sound plays only when the site is served from a web server
(not when the files are opened directly from a folder).
